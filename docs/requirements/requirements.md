## 1. Lista general de requerimientos

El sistema EventSync  tiene los siguientes requerimientos (descripción a alto nivel):

### 1.1 Requerimientos funcionales

El sistema de EventSync  debe tener la capacidad de:

1. Crear Eventos
2. Notificar Cambios
